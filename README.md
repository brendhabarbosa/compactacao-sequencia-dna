# Compactação e Descompactação de Sequências de DNA

Este projeto implementa um algoritmo de **compactação e descompactação de sequências de DNA**, alcançando uma **redução de aproximadamente 75%** no tamanho final dos arquivos.

## Dependências

O projeto utiliza a biblioteca **`bitarray`** para garantir a manipulação eficiente de bits na memória.

### Instalação

Via terminal: *pip install bitarray*
